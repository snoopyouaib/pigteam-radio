# 🖥️ Ecran tactile 4" 480x320 (ILI9488) sur N16R8 — ehRadio

> Complement de `REPRISE_PROJET_webradio.md`. Valide le 8 novembre 2026 : affichage, tactile, carte SD et son PCM5102 OK, montage soude propre. Tactile retouche le 8 nov. (appui long pour la SD) : « bien mieux ».

## Module
- Achat : « 4,0 pouces SPI 480*320 TFT, ILI9488, tactile resistif (XPT2046) », ref. dalle HSD-9190J-A3, serigraphie « V1.1 ».
- Controleur = **ILI9488** (pas ST7796S : le choix `ECRAN 2` ne convient pas a ce module).
- Les broches SCK/MOSI du TFT et du tactile **ne sont pas reliees** sur le module : il faut les doubler (point commun soude).

## Cablage final (N16R8)
| Module | ESP32-S3 |
|---|---|
| SCK + T_CLK | GPIO 12 (bus SPI A) |
| SDI (MOSI) + T_DIN | GPIO 11 |
| T_DO (MISO du tactile) | GPIO 13 |
| **SDO (MISO ecran)** | **NON BRANCHE** (l'ILI9488 ne libere pas la ligne) |
| CS / DC / RESET | GPIO 10 / 9 / 8 |
| T_CS | GPIO 14 |
| T_IRQ | non branche |
| LED / VCC | 3,3 V (5 V si trop sombre) |
| SD_SCK / SD_MOSI / SD_MISO (bus SPI B) | GPIO 18 / 47 / 21 |
| SD_CS | GPIO 17 |

## Son PCM5102 (cote droit de la carte, loin du SPI ecran)
| PCM5102 | ESP32-S3 |
|---|---|
| DIN / BCK / LCK | GPIO 42 / 41 / 40 |
| VIN | 3,3 V |
| GND, SCK, FLT, DMP, FMT | GND (SCK/FLT/DMP/FMT soudes a GND sur le module) |
| XMT | 3,3 V (a GND = son coupe) |

Connecteur **JST 6 broches**, fils de 7 cm, torsade : 1 = 3,3 V, 2 = GND, 3 = DIN (42), 4 = BCK (41), 5 = LCK (40), 6 = GND. Son « nickel ». Le module accepte 3,3 V a 5 V (regulateur LDO a bord, selon la fiche du vendeur).

## Configuration
- `myoptions.h` : `#define ECRAN 3` (0 = ILI9341, 1 = OLED, 2 = ST7796S, 3 = ILI9488), I2S `42/41/40`, SD `SPIB_SCK 18, SPIB_MOSI 47, SPIB_MISO 21, SD_SPI 'B', SD_CS 17`. Ecran retourne de 180° : `SCREEN_FLIP true`, `TOUCH_FLIP true` (valeurs pour carte neuve ; sur la carte, cases « Inverser l'ecran / Inverser tactile » du WebUI). `TS_SWIPE_THRESHOLD_PX 40` (defaut 20 ; 15 si les petits glissements sont pris pour des touchers), `TS_LONGPRESS_MS` (defaut 1200).
- `platformio.ini`, env `ehradio_s3_n16r8` : le `build_src_filter` doit contenir
  `+<libraries/ILI9488/*>` et `+<libraries/Adafruit_ST7796S/*>` (sinon erreurs de link `undefined reference to ILI9486_SPI::...`). Aucune lib_deps a ajouter (SD du framework deja prise).
- Flash : `pio run -e ehradio_s3_n16r8 -t upload` (pas d'`uploadfs` pour un changement de code).
- Apres un reflash : SAFE MODE (Smartstart desactive) jusqu'a 30 s stables ; lancer la lecture a la main.

## Tactile : gestes et patch `src/core/touchscreen.cpp`
- Glissement horizontal = volume, vertical = liste des stations, **toucher simple = lecture/arret (immediat)**, **appui long immobile (1,2 s) = bascule radio <-> SD**. Le double-tap d'origine est supprime (trop de faux declenchements) ; la veille profonde au tactile n'est plus atteignable (de toute facon desactivee).
- Bug corrige (upstream, perdu a chaque mise a jour d'ehRadio) : sur un ecran lent comme l'ILI9488, le 1er pas d'un glissement vertical etait pris pour un pas de **volume** (course entre `putRequest(NEWMODE, STATIONS)` asynchrone et `controlsEvent`, qui voit encore le mode PLAYER) puis le geste restait bloque en mode VOL. Patch : en mode PLAYER on demande seulement STATIONS (et on memorise `touchStation`) ; les pas de liste ne sont envoyes qu'en mode STATIONS.
- Les gestes rapides (2 a 5 echantillons, < 20 px) sont pris pour des touchers simples : glisser doucement sur 2 a 3 cm.
- Fichiers patches a refaire apres une mise a jour d'ehRadio (le depot git permet de les retrouver) : `controls.cpp`, `audiohandlers.cpp`, `dspfont.h`, `display.cpp` (voir `CARTES_Tiny_Zero_commandes.md`) et `touchscreen.cpp`.
- Debug du tactile : case `dbgtouch` dans `settings.html` (valeurs brutes `[Touch] x, y` dans le moniteur serie).

## Particularites ILI9488 dans ehRadio
- 24 bits par pixel, SPI fixe a 40 MHz : rafraichissement plus lent, playlist en mode pages (automatique).
- Couleurs inversees : `#define DSP_INVERT_QUIRK true`.
- Evolution possible : 4" ST7796S + tactile capacitif (FT6336/GT911, I2C), plus rapide et sans rebonds ; a verifier sur la fiche du vendeur avant achat.
