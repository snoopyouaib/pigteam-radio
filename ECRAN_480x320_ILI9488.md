# 🖥️ Ecran tactile 4" 480x320 (ILI9488) sur N16R8 — pigteam-radio

> Complement de `REPRISE_PROJET_webradio.md`. Valide le 8 novembre 2026 : affichage, tactile, carte SD et son PCM5102 OK, montage soude propre. Brochage final (RESET en 3, SD cote droit) et tactile retouche (appui long pour la SD) valides le meme jour : « bien mieux ». **Mise a jour du 9 novembre 2026** : luminosite reglable (LED sur GPIO 4) et depot passe en projet independant `pigteam-radio` (voir plus bas).

## Module
- Achat : « 4,0 pouces SPI 480*320 TFT, ILI9488, tactile resistif (XPT2046) », ref. dalle HSD-9190J-A3, serigraphie « V1.1 ».
- Controleur = **ILI9488** (pas ST7796S : le choix `ECRAN 2` ne convient pas a ce module).
- Les broches SCK/MOSI du TFT et du tactile **ne sont pas reliees** sur le module : il faut les doubler (point commun soude).
- **Retroeclairage commandable** : au dos, la broche `LED` est reliee (continuite verifiee au multimetre) a la resistance R6 (1 kΩ) du transistor Q1 : la broche ne fait que piloter la base du transistor, le GPIO ne fournit que quelques mA. Les 80 a 100 mA du retroeclairage passent par Q1.

## Cablage final (N16R8)
| Module | ESP32-S3 |
|---|---|
| SCK + T_CLK | GPIO 12 (bus SPI A) |
| SDI (MOSI) + T_DIN | GPIO 11 |
| T_DO (MISO du tactile) | GPIO 13 |
| **SDO (MISO ecran)** | **NON BRANCHE** (l'ILI9488 ne libere pas la ligne) |
| CS / DC | GPIO 10 / 9 |
| **RESET** | **GPIO 3** (strapping JTAG, sans effet avec la config par defaut ; evite le 46, qui bloque le flash si l'ecran le tire a 1) |
| T_CS | GPIO 14 |
| T_IRQ | non branche |
| **LED** | **GPIO 4** (PWM, commande le transistor Q1 ; ne plus la relier au 3,3 V) |
| VCC | 3,3 V (5 V si trop sombre) |
| SD_SCK / SD_MOSI / SD_MISO (bus SPI B) | GPIO 48 / 47 / 21 (cote droit, se suivent) |
| SD_CS | GPIO 2 |

GPIO 48 = LED RGB sur certaines versions de la carte : elle clignote avec l'horloge SD, sans danger (constate : ne gene pas). A eviter pour la SD : 45 (strapping VDD_SPI), 19/20 (USB), 46 (strapping boot).

## Son PCM5102 (cote droit de la carte, loin du SPI ecran)
| PCM5102 | ESP32-S3 |
|---|---|
| DIN / BCK / LCK | GPIO 42 / 41 / 40 |
| VIN | 3,3 V |
| GND, SCK, FLT, DMP, FMT | GND (SCK/FLT/DMP/FMT soudes a GND sur le module) |
| XMT | 3,3 V (a GND = son coupe) |

Connecteur **JST 6 broches**, fils de 7 cm, torsade : 1 = 3,3 V, 2 = GND, 3 = DIN (42), 4 = BCK (41), 5 = LCK (40), 6 = GND. Son « nickel ». Le module accepte 3,3 V a 5 V (regulateur LDO a bord, selon la fiche du vendeur). Un adaptateur existe aussi pour le MAX98357 (placements differents entre les deux modules son ; fonctionne).

## Configuration
- `myoptions.h` : `#define ECRAN 3` (0 = ILI9341, 1 = OLED, 2 = ST7796S, 3 = ILI9488), `TFT_RST 3`, I2S `42/41/40`, SD `SPIB_SCK 48, SPIB_MOSI 47, SPIB_MISO 21, SD_SPI 'B', SD_CS 2`. **Luminosite : `#define BRIGHTNESS_PIN 4` et `#define DSP_DIMMING_ENABLED true`** (dans la branche des ecrans SPI, `ECRAN` 0, 2 et 3 ; teste et fonctionnel le 9 novembre). Ecran retourne de 180° : `SCREEN_FLIP true`, `TOUCH_FLIP true` (valeurs pour carte neuve ; sur la carte, cases « Inverser l'ecran / Inverser tactile » du WebUI). Tactile : `TS_SWIPE_THRESHOLD_PX 15` (defaut 20), `TS_LONGPRESS_MS 1500` (defaut du patch 1200). `RADIO_BROWSER_NO_SEND_CLICKS` actif (plus de `[RB Click]` dans le log).
- `platformio.ini`, env `ehradio_s3_n16r8` : le `build_src_filter` doit contenir
  `+<libraries/ILI9488/*>` et `+<libraries/Adafruit_ST7796S/*>` (sinon erreurs de link `undefined reference to ILI9486_SPI::...`). Aucune lib_deps a ajouter (SD du framework deja prise).
- Flash : `pio run -e ehradio_s3_n16r8 -t upload` (pas d'`uploadfs` pour un changement de code).
- Apres un reflash : SAFE MODE (Smartstart desactive) jusqu'a 30 s stables ; lancer la lecture a la main.
- Tailles (9 nov. 2026) : N16R8 39 % de la partition, Tiny 78 %, Zero 91 % (le Zero est presque plein : toute nouvelle fonction doit etre reservee au N16R8/Tiny avec un `#ifdef`).

## Tactile : gestes et patch `src/core/touchscreen.cpp`
- Glissement horizontal = volume, vertical = liste des stations, **toucher simple = lecture/arret (immediat)**, **appui long immobile (1,5 s) = bascule radio <-> SD**. Le double-tap d'origine est supprime (trop de faux declenchements) ; la veille profonde au tactile n'est plus atteignable (de toute facon desactivee).
- Bug corrige (upstream) : sur un ecran lent comme l'ILI9488, le 1er pas d'un glissement vertical etait pris pour un pas de **volume** (course entre `putRequest(NEWMODE, STATIONS)` asynchrone et `controlsEvent`, qui voit encore le mode PLAYER) puis le geste restait bloque en mode VOL. Patch : en mode PLAYER on demande seulement STATIONS (et on memorise `touchStation`) ; les pas de liste ne sont envoyes qu'en mode STATIONS.
- Les gestes rapides (2 a 5 echantillons, < 20 px) sont pris pour des touchers simples : glisser doucement sur 2 a 3 cm.
- Debug du tactile : case `dbgtouch` dans `settings.html` (valeurs brutes `[Touch] x, y` dans le moniteur serie).

## Particularites ILI9488 dans ehRadio
- 24 bits par pixel, SPI fixe a 40 MHz : rafraichissement plus lent, playlist en mode pages (automatique).
- Couleurs inversees : `#define DSP_INVERT_QUIRK true`.

## Pistes d'evolution (ecran / carte)
- **Waveshare 3.5" capacitif 320x480** (SKU 29318, ST7796S + FT6336U, IPS, 18,99 $ sur waveshare.com ; aussi rlx.sk 21,08 € TTC) : broche `LCD_BL` pour le retroeclairage, tactile I2C (TP_SDA, TP_SCL, TP_INT, TP_RST) : `ECRAN 2` + `TS_MODEL_FT6336`, 4 fils de plus. Plus rapide que l'ILI9488. Pas indispensable depuis que la luminosite est reglable sur le 4" actuel.
- **Carte Waveshare ESP32-S3-Touch-LCD-3.5** (ST7796 + FT6336, ES8311, AXP2101, RTC PCF85063, TF) : GPIO libres sur le connecteur 32 broches : 9, 10, 11, 17, 18, 21, 38 a 42, 45 a 48, 43/44 (UART), I2C 7/8 partage. **GPIO 40/41/42 = brochage I2S actuel (PCM5102 reutilisable tel quel)**. Pas d'ES8311 gere par ehRadio. La version **3.5B** est en QSPI (AXS15231B) : incompatible avec ehRadio. Brochage interne ecran/tactile/SD/retroeclairage a recuperer sur le wiki Waveshare avant tout achat.
- Module **TP4056** (chargeur USB-C + protection) et module **power bank tout-en-un** (USB-C, boost 5 V, 4 LED, bouton K, self 2R2, probablement IP5306) retrouves dans le tiroir : le second est le bon pour une version sur batterie (chrono GPS ou radio portable). Non utilises par la radio de bureau.
